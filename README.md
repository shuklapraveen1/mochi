# Mochi <img src="assets/icon128.png" width="28" alt="Mochi">

A tiny 8-bit pixel companion for chatbots.

Mochi adds a small pixel character to your conversations, with simple emotions and actions.

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions/` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the `mochi` folder.

Open a supported chatbot and start chatting.

## Features

- Pixel-art emotions and animations
- Lightweight and unobtrusive
- Private by design: no accounts, no data collection, and no conversation data is sent anywhere
